# LV 1000 Slime Dungeon
LV 1000 Slime Dungeon é um jogo de arena swarm 2.5D desenvolvido para a Mini Jam 202 (Tema: Power-up). O jogo coloca o jogador em um calabouço onde deve sobreviver a hordas de slimes, coletando power-ups para evoluir e enfrentar desafios cada vez maiores.

O projeto alcançou a 80ª posição entre 161 jogos enviados na competição.

## Especificações Técnicas
Engine: Godot Engine 4 (GDScript).

Estilo Visual: 2.5D (Ambiente 3D com sprites 2D).

Assets de Arte: Criados no Aseprite.

Filosofia de Código: Desenvolvimento 100% autoral, sem o uso de ferramentas de IA (LLMs) para programação, prezando pela lógica manual e documentação oficial.

## Funcionalidades e Implementações
Sistema de Swarm: Gerenciamento de dezenas de inimigos simultâneos na tela lutando contra o jogador.

Mecânica de Power-up: Sistema de progressão onde o jogador coleta itens para aumentar seu poder de ataque e sobrevivência.

Arquitetura de Código: Implementação focada em desacoplamento e performance, utilizando padrões como Signal Bus e Data-Driven design via Godot Resources.

## Como Jogar
Enfrente as hordas de slimes que surgem na arena.

Colete os power-ups deixados pelos inimigos ou espalhados pelo mapa.

Sobreviva o máximo de tempo possível enquanto aumenta seu nível.
